Logo LIES AI is an advanced AI and machine learning platform engineered to detect counterfeit product logos and brand infringements in real time. Built on a Flask web framework with a responsive dashboard interface, the system employs a multi-tiered forensic detection pipeline: high-speed YOLOv8 object detection rapidly identifies known brand logos, EasyOCR extracts and verifies embedded text, and Google Gemini Vision acts as a multimodal fallback to perform deep visual inspection when subtle anomalies or novel counterfeits are encountered. Additionally, the platform features an integrated AI chat assistant, secure user authentication with email OTP verification, real-time hardware telemetry, and an analytics suite that tracks scan histories, authenticity ratios, and downloadable reports in both Excel (.xlsx) and Word (.docx) formats.
